# Notebooks — Aula de IA: Generalização e Regularização

Este pacote contém 3 notebooks em PyTorch voltados para tomada de decisão em aprendizado supervisionado.

## Arquivos
- `01_diagnostico_overfitting.ipynb`
- `02_regularizacao_excessiva.ipynb`
- `03_comparacao_estrategias_generalizacao.ipynb`

## Propósito didático
Os notebooks não foram construídos como tutoriais lineares.  
Eles foram organizados como **cenários de decisão**, nos quais o aluno precisa:

1. executar;
2. observar sintomas;
3. diagnosticar;
4. intervir;
5. comparar resultados;
6. justificar escolhas.

## Requisitos
- Python 3.10+
- PyTorch
- scikit-learn
- matplotlib
- pandas
- Jupyter Notebook ou VS Code com suporte a notebooks

## Competência central
Mais do que "usar dropout", o aluno deve aprender a **tomar decisão em ML com base em evidência**.
